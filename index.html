Formularios en HTML

Texto

Campos de texto basicos: simple, con placeholder, obligatorio(Required), de solo lectura (readonly) y deshabilitado (disabled).





Contacto

Campos especializados para datos de contacto: contraseña, correo electronico, telefono y url, cada uno con su propio teclado y validacion en el navegador




Numericos

Campos para valores numericos: un numero con limites (min/max) y un deslizados (range) para elegir un valir dentor de un rango



Fecha y hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semana del año y mes.





Seleccion

Controles de selección: elegir un color, marcar una casilla, elegir una opción de un grupo de radios y subir un archivo.





Listas desplegables

Listas desplegables con el elemento select: una opción simple, una con valor preseleccionado (selected), una agrupada con optgroup, una de selección múltiple (multiple) y una deshabilitada (disabled).
